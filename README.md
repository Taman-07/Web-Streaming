# Video Streaming Platform

A modern video streaming platform built with the **MERN stack** with an AI-powered recommendation system that delivers personalized content feeds based on user interests and watching behavior.

---

## Overview

AIStream aims to provide a next-generation streaming experience where users can:

- Upload and watch videos
- Stream videos in multiple qualities
- Discover personalized content through AI recommendations
- Interact with creators and communities

The platform combines **full-stack development + AI recommendation systems** to create a smarter streaming experience.

---

## Features

###  Video Platform
- Upload and manage videos
- Multiple video quality support (360p, 480p, 720p)
- Smooth video streaming
- Video metadata management

### User Experience
- Authentication & user profiles
- Personalized home feed
- Watch history
- Likes, comments and subscriptions

### AI Recommendation System
- Learns user interests from watching patterns
- Personalized infinite scrolling feed
- Content similarity-based recommendations
- Smart video discovery
